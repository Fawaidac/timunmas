🔄 PERUBAHAN MAJOR
───────────────────────────────────────────────────────────────────────────────

DATABASE
  [OLD] Firebird dengan raw SQL query
  [NEW] MySQL dengan Eloquent ORM

AUTHENTICATION
  [OLD] Custom dengan Firebird f_ibpassword()
  [NEW] Custom dengan Laravel Hash::make() / Hash::check()

MODELS LOCATION
  [OLD] app/ModelName.php
  [NEW] app/Models/ModelName.php

ROUTE SYNTAX
  [OLD] Route::get('/', 'Controller@method')
  [NEW] Route::get('/', [Controller::class, 'method'])

VALIDATION
  [OLD] Manual validation di controller
  [NEW] $request->validate() (siap upgrade ke Form Request)

QUERY BUILDER
  [OLD] DB::select('select * from ...', [...])
  [NEW] Model::where()->get() (Eloquent ORM)

───────────────────────────────────────────────────────────────────────────────
⚠️  YANG PERLU DIPERHATIKAN
───────────────────────────────────────────────────────────────────────────────

❗ DATA MIGRATION
   Project ini hanya migrasi STRUKTUR & LOGIC, belum termasuk migrasi DATA
   dari Firebird ke MySQL. Untuk migrasi data, Anda perlu:
   - Export data dari Firebird
   - Transform sesuai struktur MySQL
   - Import ke MySQL

❗ PASSWORD HANDLING
   Password di Firebird menggunakan f_ibpassword() custom function.
   Di Laravel 10 sudah pakai Hash::make() standard.
   User existing perlu password reset atau rehash manual.

❗ FIELD NAMING
   Beberapa field mungkin case-sensitive di MySQL vs Firebird.
   Semua nama table & field sudah di-lowercase untuk MySQL convention.

❗ VIEW ADJUSTMENT
   Blade views sudah dicopy, tapi mungkin perlu minor adjustment untuk:
   - Field names (uppercase → lowercase)
   - Relationships (bisa simplify dengan Eloquent)
   - Session variables (nmuser, nootor)
